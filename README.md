# For Aaisha ♡ — Birthday Website

A small, responsive, interactive birthday website built with plain HTML, CSS, and JavaScript.

## Run it
1. Extract the ZIP.
2. Open `index.html` in a modern browser.
3. For best results, host the folder on GitHub Pages or use a local server.

## Add your background music
1. Put your own MP3 file inside the `assets` folder.
2. Rename it to `your-song.mp3` **or** edit the audio source in `index.html` to match your filename:
   ```html
   <source src="assets/your-song.mp3" type="audio/mpeg">
   ```
3. Keep the file path and filename exactly the same (case-sensitive on many hosts).
4. Music starts after the visitor taps the bow. Browsers commonly block autoplay before a user interaction.

The ZIP intentionally does not include a copyrighted song. Add a song you have permission to use.

## Customize
- Edit the wishes and letter in `index.html`.
- Change colours, fonts, and layout in `style.css`.
- Change interactions and the rotating compliments in `script.js`.

## Files
- `index.html` — pages and content
- `style.css` — styling and fade transitions
- `script.js` — bow interaction, navigation, music controls
- `assets/` — place your music file here
